Prompt Hacker Academy
About the Project

Prompt Hacker Academy is a game made using PenguinMod and PangAI to help children learn how to use AI properly. The game teaches players how to write better prompts using missions, score bars, feedback, and AI interaction.

Players learn:

Prompt engineering
AI literacy
Responsible AI usage
Creative thinking
Main Features
Prompt quality scanner
AI safety filter
PangAI response system
XP and level system
Animated score bars
Typewriter AI output
Creative and Study AI modes

Educational Purpose

This project helps children:

Learn future technology skills
Improve communication with AI
Practice creativity and critical thinking
Understand safe AI usage
